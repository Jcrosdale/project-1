My development process involved starting with its basic structure, moving to the design, and then to the functionality. I fetched data from the API early on in the process to ensure I had the correct API key, since the country card is a major portion of the website. Since the design elements outside the country card were minimal, it made it easier to move to that feature next within the JS file. Once the country cards were displaying, I moved to creating event listeners that could respond to filtering the regions and search input. Having the core functionality down allowed me to circle back to the design part, such as more accessibility, responsive design, and dark mode.

One challenge I faced was encountering errors when trying to pull from the API files using the API key. After testing through multiple errors, I realized I needed to create an API key with CORS enabled that would allow my domain origin to pull data. After that, there was a lot of trial and error when it came to getting the images of the flag to load. I realized that a forEach loop could be useful in this case because then the same features could be added to each element in the array without me manually doing them. Some of the DOM elements were outside the loop, but I added them inside to correct it. Adding console logs throughout the development process helped significantly to ensure everything is connected correctly before adding the logic.

Potential improvements include adding other elements such as a map or images. A way to save countries to a favorites list. A way to compare countries and view them side-by-side.
