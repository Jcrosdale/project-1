Project - Open World Search

Uses the REST Countries API JSON to search, filter, and display country data. It can also toggle between light and dark mode through the Light/Dark Mode button. Users can search for a country through the search bar. Countries that fit what was searched will only be displayed. Users can also filter by region, and countries under that region will only be displayed. If an object element was not provided for a country, only the information the country has will be displayed.
